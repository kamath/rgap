`@rgap/server` exposes the repository through a Hono HTTP API. Its route
declarations are the single source for runtime validation, OpenAPI, Hono RPC
types, and the generated fetch client.

## Start the server

```bash
pnpm --filter @rgap/server dev
```

The server uses these environment variables:

| Variable | Purpose | Default |
| --- | --- | --- |
| `RGAP_DATABASE_URL` | SQLite database path | Package default |
| `RGAP_ADMIN_TOKEN` | Administrative bearer for trusted operations | `test` |

The generated reference is authoritative for endpoint paths, inputs, response
schemas, and status codes. This guide focuses on how requests select an
authorization plane.

## Select a repository plane

Every command request carries an authorization header:

```http
Authorization: Bearer <token>
```

- An RGAP bearer selects `store.as(token)`.
- The configured administrative bearer selects `store.admin()`.

The administrative plane is intended for trusted bootstrap and operational
calls, including root creation and reset. Keep it behind an infrastructure
authentication boundary.

## Make an authorized request

```bash
curl http://localhost:3000/resources \
  --request POST \
  --header 'Authorization: Bearer test' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "acme/platform/tools/search",
    "executable": { "runtime": "search" }
  }'
```

`POST /resources` and `POST /grants` accept a slash-separated location in
`name` and return the leaf. The path is the location; the body does not include
`parentId`. Missing resource prefixes are folders created from the forest root.
The resource leaf is a folder when `executable` is absent and an executable
resource when it is present. A grant write also carries the leaf binding set
and expiration; every grant created in that walk stores those fields.

`PATCH /resources/{id}` accepts any non-empty combination of `name` and
`parentId` and atomically renames or reparents the resource. `executable`
belongs to `POST /resources` only: a definition is sealed by create, cannot be
patched afterward, and is retired by deleting the resource with
`DELETE /resources/{id}`.

Grant bindings can be replaced as one atomic set:

```http
PUT /grants/{id}/bindings
Content-Type: application/json

{"bindings":[{"id":"resource_id","permissions":["read"]}]}
```

Successful requests return the JSON-compatible RGAP records and decisions
described by the generated schema. Commands with no response value return
`204`.

## Generate the TypeScript client

```bash
pnpm --filter @rgap/server generate
```

The command derives `openapi.json` from Hono's route declarations, then runs
HeyAPI to generate a fetch-based SDK and model types. Generated output is not
committed.

<Callout type="warn" title="Do not treat Swagger UI as an administrative boundary">
  The OpenAPI document and interactive UI are public documentation routes. The
  command routes still require a bearer and enforce the selected repository
  plane.
</Callout>
