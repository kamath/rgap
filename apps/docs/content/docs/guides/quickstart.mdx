This walkthrough uses the TypeScript packages in the RGAP repository with an
in-memory SQLite database.

## Install and build

```bash
git clone https://github.com/kamath/rgap.git
cd rgap
pnpm install
pnpm build
```

The repository includes an editable scratchpad at `examples/index.ts`. Run it
with:

```bash
pnpm scratch
```

## Create a store

Create a SQLite-backed store and explicitly select its administrative plane.
The administrative plane is for trusted bootstrap code.

```ts
import { SqliteRgapStore } from '@rgap/sqlite';

const store = new SqliteRgapStore({ url: ':memory:' });
const admin = store.admin();
```

## Build the resource tree

```ts
const acme = await admin.resources.create({ name: 'acme' });
const platform = await acme.create({ name: 'platform' });
const docs = await platform.create({ name: 'docs' });
const design = await docs.create({ name: 'design' });
```

The returned handles carry both their record fields and the commands that apply
to them.

```text
acme/
└── platform/
    └── docs/
        └── design
```

## Create the root grant

Root grants are administrative because no grant exists above them to bound
their authority.

```ts
const company = await admin.grants.create({
  name: 'Company',
  capabilities: [],
  expiresAt: null,
});

await company.capabilities.set([
  {
    resourceId: acme.id,
    permissions: ['read', 'write', 'invoke'],
  },
]);
```

## Issue a token

```ts
const issued = await company.tokens.create({ label: 'platform-service' });
const companyPlane = store.as(issued.value);
```

`issued.value` is the one-time bearer secret. The token record in the store
contains only its hash.

## Delegate less authority

Create a child grant from the token-selected plane. This child reaches only the
documentation subtree and holds fewer permissions.

```ts
const agent = await companyPlane.grants.create({
  name: 'Documentation agent',
  capabilities: [],
  expiresAt: null,
});

await agent.capabilities.set([
  {
    path: 'acme/platform/docs',
    permissions: ['read'],
  },
]);
```

RGAP proves that the child path sits inside the root grant's resource subtree
and that `read` is included in the parent's permission set.

## Exercise the delegated plane

```ts
const agentToken = await agent.tokens.create({ label: 'research-run' });
const agentPlane = store.as(agentToken.value);

const visibleDesign = await agentPlane.resources.get(design.id);
console.log(visibleDesign.name); // "design"

const decision = await agentPlane.authorize(
  agentToken.value,
  design.id,
  'read',
);
console.log(decision.allowed); // true
```

A write against the same resource is denied because the agent's grant contains
only `read`.

## Revoke the branch

```ts
await company.revoke();
```

The company grant, documentation agent grant, and every token beneath them are
inactive on the next authorization check.
