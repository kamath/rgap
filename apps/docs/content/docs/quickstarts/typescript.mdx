This quickstart runs against an in-memory SQLite database and exercises the
same repository interface used by durable and HTTP-backed stores.

## Set up the repository

1. Clone `https://github.com/kamath/rgap.git`.
2. Run `pnpm install` from the repository root.
3. Open the included `examples/quickstart.ts` file shown in full below.

## Review the complete example

```ts title="examples/quickstart.ts"
import { SqliteRgapStore } from '@rgap/store-sqlite';

const store = new SqliteRgapStore({ url: ':memory:' });

try {
  const admin = store.admin();

  const design = await admin.resources.create({
    name: 'acme/platform/docs/design',
  });

  const agent = await admin.grants.create({
    name: 'company/documentation-agent',
    bindings: [{
      id: design.id,
      permissions: ['read'],
    }],
    expiresAt: null,
  });

  const agentToken = await agent.tokens.create({
    label: 'research-run',
  });
  const agentPlane = store.as(agentToken.value);

  const visibleDesign = await agentPlane.resources.get(design.id);
  const read = await agentPlane.authorize(
    agentToken.value,
    design.id,
    'read',
  );
  const write = await agentPlane.authorize(
    agentToken.value,
    design.id,
    'write',
  );

  console.log({
    resource: visibleDesign.name,
    read: read.allowed,
    write: write.allowed,
  });

  await agent.revoke();

  const afterRevocation = await agentPlane.authorize(
    agentToken.value,
    design.id,
    'read',
  );

  console.log({
    readAfterAncestorRevocation: afterRevocation.allowed,
  });
} finally {
  store.close();
}
```

## Run it

From the repository root, run
`pnpm --filter @rgap/examples exec tsx quickstart.ts`.

The first result reports the `design` resource with `read: true` and
`write: false`. The second reports `readAfterAncestorRevocation: false`.

## What the file demonstrates

- Resources form a mutable hierarchy with stable identities.
- One grant create materializes the `company/documentation-agent` grant path.
- Each grant created in that path binds `read` under `acme/platform/docs` from
  the create body.
- The agent's repository plane can read `design` but cannot write it.
- Revoking the agent grant disables its token on the next authorization check.
